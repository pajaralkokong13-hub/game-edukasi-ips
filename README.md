# 🏛️ Ekonomi Quest: Tantangan Ujian Madrasah IPS

Gim kuis edukasi interaktif berbasis web yang disusun berdasarkan **Kisi-Kisi Ujian Madrasah Mata Pelajaran Ilmu Pengetahuan Sosial (IPS) MA Madinatunnajah Tahun Pelajaran 2025/2026**.

## ✨ Fitur Utama
* **Ilustrasi Visual Dinamis (SVG):** Setiap materi dilengkapi diagram visual yang relevan, seperti grafik harga keseimbangan ($E$), kurva permintaan ($D$), kurva penawaran ($S$), struktur pengawasan OJK, hingga ilustrasi uang digital dan pasar.
* **Variasi Tipe Soal Lengkap:**
  * **Pilihan Ganda (PG):** Menguji pemahaman konsep dasar ekonomi.
  * **Pilihan Ganda Kompleks (PGK):** Melatih ketelitian dengan memilih lebih dari satu jawaban benar.
  * **Menjodohkan Konsep:** Interaksi klik-pasang antar istilah dan definisi ekonomi.
  * **Benar / Salah:** Evaluasi cepat ketepatan konsep.
  * **Analisis Studi Kasus:** Penerapan konsep pasar modern, *e-commerce*, dan kebijakan harga.
* **Mekanisme Tantangan Seru:** Dilengkapi sistem **3 Nyawa (❤️)**, batas waktu **45 detik** per soal, serta **Bonus Kombo (🔥)** untuk jawaban benar beruntun.
* **Pembahasan Instan:** Penjelasan materi langsung muncul setelah siswa menjawab soal.
* **Ringan & Responsif:** Dibangun dalam satu file `index.html` murni tanpa *framework* eksternal, lancar dibuka melalui HP maupun laptop.

## 📚 Cakupan Materi Kisi-Kisi
1. **Permintaan, Penawaran, dan Harga Keseimbangan** (Hukum, bentuk kurva, pergeseran titik keseimbangan).
2. **Uang dan Alat Pembayaran** (Uang kartal, uang giral, fungsi asli uang, serta manfaat uang elektronik/QRIS).
3. **Lembaga Keuangan & OJK** (Kepanjangan dan tujuan OJK, lembaga keuangan bank dan nonbank seperti Pegadaian dan Asuransi).
4. **Dinamika Pasar** (Jenis pasar berdasarkan waktu, karakteristik pasar tradisional, serta dampak perkembangan supermarket dan *e-commerce*).

## 🚀 Cara Menjalankan Melalui GitHub Pages
1. Unggah atau simpan kode permainan ke dalam file bernama `index.html` di *repository* ini.
2. Buka tab **Settings** pada *repository* GitHub Anda.
3. Pilih menu **Pages** di bilah samping kiri.
4. Pada bagian **Build and deployment > Branch**, pilih `main` (atau `master`), biarkan folder di `/ (root)`, lalu klik **Save**.
5. Tunggu 1–2 menit hingga tautan situs aktif muncul di bagian atas halaman **Pages**, lalu bagikan tautan tersebut kepada siswa.
