# game-edukasi-ips
Gim edukasi interaktif berbasis web untuk latihan Kisi-Kisi Ujian Madrasah IPS MA Madinatunnajah 2025/2026. Dilengkapi ilustrasi kurva ekonomi, fitur nyawa, timer, skor kombo, pembahasan instan, serta variasi soal PG, PG Kompleks, Menjodohkan, dan Benar/Salah guna menguasai materi pasar, permintaan-penawaran, uang, dan OJK secara seru dan mudah.
